# Regole sui branch

- Non creare nuovi branch di tua iniziativa: decide l'utente quando serve un branch.
- Si lavora direttamente su `develop`, salvo richiesta esplicita di creare un branch.
- Se l'utente chiede un branch, usa il nome che indica; se non lo indica, chiediglielo.
- Mai branch con nomi casuali o generati automaticamente (es. `claude/...`, `ccr-...`, `feature-123`): il nome lo sceglie l'utente.
- Non fare commit o push su un branch diverso da quello indicato dall'utente.
